# react-dynamic-datepicker demo

Next.js demo for [react-dynamic-datepicker](https://www.npmjs.com/package/react-dynamic-datepicker).

Live: https://react-dynamic-datepicker.vercel.app

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/
```

## Deploy on Vercel

1. Import the GitHub repo at https://vercel.com/new.
2. Set **Root Directory** to `demo`. Vercel detects Next.js; keep the default build settings.
3. Deploy. If the domain differs from https://react-dynamic-datepicker.vercel.app, update `homepage` in the
   package's package.json, the demo link in its README, and `NEXT_PUBLIC_SITE_URL`.
